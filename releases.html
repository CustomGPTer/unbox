Release notes

What changed in each version of Unbox. The newest is at the top.

Version 1.0.0 26 November 2026Latest

  • First release. A private APK extractor and backup manager with no internet access.
  • Split apps saved complete as .apks bundles (or the main file only, or ask each time), with every file checked by SHA-256 after saving.
  • Batch extraction with progress for each app; swipe to extract; file-name templates.
  • Filters for source, split or single, last updated, first installed, target Android, size, enabled, hidden, debuggable and trackers, with saved filter sets; search by name, package or permission; seven sorts; cards, compact or grid.
  • App details: split files explained, processor support, permissions, signing certificate, components and a searchable manifest viewer.
  • Backups grouped by app with every version, a watch list that saves new versions automatically, and a built-in installer for .apk, .apks and .xapk files.
  • Insights: install sources, target Android versions, biggest apps (optionally with data and cache), recent updates and an offline tracker scan.
  • CSV and PDF app lists, save any app's icon, an Extract latest widget and pull-down tile, app lock, six accent colours, dark, light, pure black and wallpaper colours.

Checking your download

The file for version 1.0.0 is called Unbox.apk. It is 4.6 MB (4,839,294 bytes). Its SHA-256 checksum is:

e8c03c2ae98e847cb5b50366578da5b3d012d48f13a334949f7dcf08198f59e2

On Windows, run certutil -hashfile Unbox.apk SHA256 and compare. Every version is signed with the same key, so each one installs over the last and keeps what you have saved.

Older versions are on the GitHub releases page.
