# Unbox

Unbox saves the apps on your Android phone as files you can keep, share and reinstall: split apps as complete .apks bundles, every file checked after saving, batch extraction, a built-in installer, a watch list that keeps each new version, and powerful filters. No internet access, no adverts, no account.
