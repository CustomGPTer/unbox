**Unbox 1.0.0** — first release.

A private APK extractor and backup manager for Android 10 and later. No internet access, no adverts, no account.

- Split apps saved complete as .apks bundles, every file checked by SHA-256 after saving.
- Batch extraction, swipe to extract, file-name templates.
- Filters with saved filter sets, search by name, package or permission, cards, compact or grid.
- Full app details, split files explained, processor support, certificate, components and a manifest viewer.
- Backups by version, a watch list that saves new versions, and a built-in installer for .apk, .apks and .xapk.
- Insights, offline tracker scan, CSV and PDF lists, icon saving, an Extract latest widget and tile, app lock and themes.
